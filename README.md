# Camila Cempasuchil Tribute

ROL: Eres un diseñador UX/UI y desarrollador web senior frontend con experiencia en desarrollo en páginas creativas

TAREA: Crea una landing page para hacer un altar digital para mi mascota, la cual es un perrito y se llama Camila  CONTEXTO:

Las caracteristicas de la landing page son: -Paleta de colores vidrantes y de fondo color azul, flores de sempasuchil. -que sea interactiva al momento de pasar el cursor por algun detalle se agrande -petalos de cempasúchil cayendo -La foto de mi perrito es mediano fespul blancay china que sea realista. -un arco de flores de cempazuchitl -Guirnalda de papel picado animada en el encabezado. -Que el cursor sea en forma de patita o huellita. Que al poner el cursor en la perrita se haga un sonido de ladrido
